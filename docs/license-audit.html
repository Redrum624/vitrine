2. Chosen Project License: PolyForm Noncommercial 1.0.0

Why it fits "non-commercial including non-commercial-only derivatives"

The PolyForm Noncommercial License 1.0.0 restricts use to noncommercial purposes. Its "Changes and New Works License" section grants derivative-work rights only "for any permitted purpose" — and the only permitted purpose defined is noncommercial. This means:

  • Anyone can fork and modify the project for personal, educational, research, or charitable work.
  • Neither the original nor any derivative may be used commercially.
  • Sublicensing is expressly disallowed ("No Other Rights").

This is stronger than CC-BY-NC (which is ambiguous on derivatives) and is a purpose-built software license. It is not OSI-approved; it is "source-available, non-commercial."

Compatibility with bundled dependencies

All 18 bundled npm packages carry permissive licenses (MIT/Apache-2.0/ISC/MPL-2.0) or a weak-copyleft library license (LGPL). None carry GPL-2.0-only or AGPL that would force the project into a conflicting copyleft obligation. The project license wraps these without overriding them, as stated in the LICENSE header.

5. Build Wiring — License Files in Release

LICENSE and THIRD-PARTY-LICENSES.md are copied to release/ alongside the installer by scripts/gen-license-files.cjs, called at the end of npm run build:win — the same pattern used by scripts/gen-readme-txt.cjs for the README.txt. They are NOT in extraResources (inside the asar), but as top-level files next to the installer in release/, which is the appropriate place for distribution-facing license files.
