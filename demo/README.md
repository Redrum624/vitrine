**Icons:**
- Geometric shapes only: ▨ ◧ ◈ ◉ ◐ ◎ ◫ ◪ ⟲ ▭
- All in muted gray tones
- No color emojis

**Key Features:**
- Dense, information-rich layout
- All tools visible at once
- Professional studio aesthetic
- Inspired by Capture One Pro / Lightroom
- Maximum functionality

**Best For:**
- Professional photographers
- Power users
- Desktop-first workflows
- Users who want all controls visible

## 🎯 Design Philosophy

### **Prestigious Studio:**
"Everything at your fingertips" - Power users want all tools visible. Dense but meticulously organized layout optimizes professional workflows. Inspired by world-class photo editing studios and professional-grade software.

### **Ultra Minimal:**
"Maximum focus on the image" - Strip away everything non-essential. Let the photograph breathe. Create a calm, zen-like editing environment. The pinnacle of minimalism meets professional functionality.

### **Typography:**
- Font: System fonts (-apple-system, BlinkMacSystemFont, 'Segoe UI', etc.)

- Prestigious: Compact (8-20px gaps)

- Size: 14-18px
